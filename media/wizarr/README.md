# Wizarr — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Wizarr](https://wizarr.org) — automatic invitations and onboarding for your Jellyfin, Plex or Emby server.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/wizarr/wizarr-ubuntu.sh
chmod +x wizarr-ubuntu.sh
sudo bash wizarr-ubuntu.sh
```
