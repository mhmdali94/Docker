# What's Up Docker — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [What's Up Docker](https://getwud.github.io/wud/) — keep track of container image updates with a dashboard and notifications.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/management/wud/wud-ubuntu.sh
chmod +x wud-ubuntu.sh
sudo bash wud-ubuntu.sh
```
