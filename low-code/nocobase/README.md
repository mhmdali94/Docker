## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/low-code/nocobase/nocobase-ubuntu.sh
chmod +x nocobase-ubuntu.sh
sudo bash nocobase-ubuntu.sh
```
