# Forgejo — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Forgejo](https://forgejo.org) — self-hosted lightweight software forge (community fork of Gitea).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/dev/forgejo/forgejo-ubuntu.sh
chmod +x forgejo-ubuntu.sh
sudo bash forgejo-ubuntu.sh
```
