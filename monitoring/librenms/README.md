# LibreNMS — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [LibreNMS](https://www.librenms.org) — a fully featured network monitoring system (SNMP).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/monitoring/librenms/librenms-ubuntu.sh
chmod +x librenms-ubuntu.sh
sudo bash librenms-ubuntu.sh
```
