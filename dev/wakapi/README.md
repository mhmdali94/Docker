## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/dev/wakapi/wakapi-ubuntu.sh
chmod +x wakapi-ubuntu.sh
sudo bash wakapi-ubuntu.sh
```
