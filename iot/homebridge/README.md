# Homebridge — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Homebridge](https://homebridge.io) — bring non-HomeKit smart devices into Apple Home.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/iot/homebridge/homebridge-ubuntu.sh
chmod +x homebridge-ubuntu.sh
sudo bash homebridge-ubuntu.sh
```
