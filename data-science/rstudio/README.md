# RStudio Server — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [RStudio Server](https://posit.co/products/open-source/rstudio-server/) — the R IDE in your browser.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/data-science/rstudio/rstudio-ubuntu.sh
chmod +x rstudio-ubuntu.sh
sudo bash rstudio-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Username | `rstudio` |
| Password | Auto-generated (shown at install) |
