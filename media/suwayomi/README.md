# Suwayomi — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Suwayomi](https://github.com/Suwayomi/Suwayomi-Server) — a free manga reader server (Tachiyomi-compatible).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/suwayomi/suwayomi-ubuntu.sh
chmod +x suwayomi-ubuntu.sh
sudo bash suwayomi-ubuntu.sh
```
