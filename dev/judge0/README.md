## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/dev/judge0/judge0-ubuntu.sh
chmod +x judge0-ubuntu.sh
sudo bash judge0-ubuntu.sh
```
