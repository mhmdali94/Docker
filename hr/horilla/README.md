# Horilla HRMS — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Horilla HRMS](https://www.horilla.com) — a modern open-source HRMS (recruitment, onboarding, attendance, leave, payroll).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/hr/horilla/horilla-ubuntu.sh
chmod +x horilla-ubuntu.sh
sudo bash horilla-ubuntu.sh
```
