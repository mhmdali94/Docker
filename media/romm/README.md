# RomM — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [RomM](https://romm.app) — a beautiful ROM manager and browser-based retro game library.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/romm/romm-ubuntu.sh
chmod +x romm-ubuntu.sh
sudo bash romm-ubuntu.sh
```

## 📝 Notes

- Organize ROMs as `library/<platform>/<game>` (e.g. `library/snes/`).
- Add IGDB API credentials in settings for cover art and metadata.
