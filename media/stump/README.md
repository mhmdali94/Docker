# Stump — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Stump](https://stumpapp.dev) — a fast, Rust-based comic/manga/ebook server with OPDS support.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/stump/stump-ubuntu.sh
chmod +x stump-ubuntu.sh
sudo bash stump-ubuntu.sh
```
