# Tryton — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Tryton](https://www.tryton.org) — a modular, high-level general-purpose business platform (ERP framework).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/erp/tryton/tryton-ubuntu.sh
chmod +x tryton-ubuntu.sh
sudo bash tryton-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Database | `tryton` |
| Username | `admin` |
| Password | Auto-generated (shown at install) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8153` | Web client + JSON-RPC |

## 💻 Connect

