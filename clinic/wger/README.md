# wger — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [wger](https://wger.de) — self-hosted fitness: workout plans, exercise database, nutrition and body weight tracking.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/clinic/wger/wger-ubuntu.sh
chmod +x wger-ubuntu.sh
sudo bash wger-ubuntu.sh
```
