# Deluge — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Deluge](https://deluge-torrent.org) — a lightweight BitTorrent client with plugins.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/downloads/deluge/deluge-ubuntu.sh
chmod +x deluge-ubuntu.sh
sudo bash deluge-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| WebUI password | `deluge` (change immediately) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8237` | WebUI |
| `6883` | Peer TCP/UDP |

## 💻 Connect

```bash
http://SERVER_IP:8237
```
