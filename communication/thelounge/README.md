# The Lounge — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [The Lounge](https://thelounge.chat) — a modern, always-connected web IRC client.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/communication/thelounge/thelounge-ubuntu.sh
chmod +x thelounge-ubuntu.sh
sudo bash thelounge-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Users | Created via `docker exec -it thelounge thelounge add <name>` |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `9020` | Web UI |

## 💻 Connect

```bash
http://SERVER_IP:9020
```
