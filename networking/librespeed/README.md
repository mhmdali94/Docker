# LibreSpeed — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [LibreSpeed](https://librespeed.org) — a lightweight self-hosted speed test (HTML5, no Flash).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/networking/librespeed/librespeed-ubuntu.sh
chmod +x librespeed-ubuntu.sh
sudo bash librespeed-ubuntu.sh
```
