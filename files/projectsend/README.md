# ProjectSend — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [ProjectSend](https://www.projectsend.org) — self-hosted client-oriented file sharing with upload portals.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/files/projectsend/projectsend-ubuntu.sh
chmod +x projectsend-ubuntu.sh
sudo bash projectsend-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| DB host | `projectsend-db` |
| DB / user | `projectsend` |
| DB password | Auto-generated (shown at install) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8155` | Web UI |

## 💻 Connect

```bash
http://SERVER_IP:8155
```
