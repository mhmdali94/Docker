# Mailpit — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Mailpit](https://mailpit.axllent.org) — an email testing tool — catches all outgoing mail in a web UI (great companion for every app in this repo).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/email/mailpit/mailpit-ubuntu.sh
chmod +x mailpit-ubuntu.sh
sudo bash mailpit-ubuntu.sh
```
