## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/gaming/foundryvtt/foundryvtt-ubuntu.sh
chmod +x foundryvtt-ubuntu.sh
sudo bash foundryvtt-ubuntu.sh
```
