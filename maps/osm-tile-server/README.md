# OpenStreetMap Tile Server — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [OpenStreetMap Tile Server](https://github.com/Overv/openstreetmap-tile-server) — serve your own OpenStreetMap raster tiles — self-hosted Google Maps layer.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/maps/osm-tile-server/osm-tile-server-ubuntu.sh
chmod +x osm-tile-server-ubuntu.sh
sudo bash osm-tile-server-ubuntu.sh
```
