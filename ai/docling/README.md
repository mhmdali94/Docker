# Docling Serve — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Docling Serve](https://github.com/docling-project/docling-serve) — IBM's document parsing engine as an API — PDF/DOCX/PPTX to clean Markdown for RAG.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/ai/docling/docling-ubuntu.sh
chmod +x docling-ubuntu.sh
sudo bash docling-ubuntu.sh
```
