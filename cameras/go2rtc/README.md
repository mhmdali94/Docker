# go2rtc — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [go2rtc](https://github.com/AlexxIT/go2rtc) — the ultimate camera streaming app — RTSP, WebRTC, HomeKit, RTMP.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/cameras/go2rtc/go2rtc-ubuntu.sh
chmod +x go2rtc-ubuntu.sh
sudo bash go2rtc-ubuntu.sh
```
