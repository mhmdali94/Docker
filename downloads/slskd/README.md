# slskd — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [slskd](https://github.com/slskd/slskd) — a modern web-based Soulseek client (music sharing network).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/downloads/slskd/slskd-ubuntu.sh
chmod +x slskd-ubuntu.sh
sudo bash slskd-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Username | `slskd` |
| Password | `slskd` (change immediately) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `5030` | Web UI |
| `50300` | Soulseek listen port |

## 💻 Connect

```bash
http://SERVER_IP:5030
```
