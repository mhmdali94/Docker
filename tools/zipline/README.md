## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/zipline/zipline-ubuntu.sh
chmod +x zipline-ubuntu.sh
sudo bash zipline-ubuntu.sh
```
