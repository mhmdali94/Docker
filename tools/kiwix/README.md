# Kiwix — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Kiwix](https://kiwix.org) — serve offline copies of Wikipedia, StackOverflow, Project Gutenberg and more.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/kiwix/kiwix-ubuntu.sh
chmod +x kiwix-ubuntu.sh
sudo bash kiwix-ubuntu.sh
```
