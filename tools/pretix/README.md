# pretix — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [pretix](https://pretix.eu) — professional open-source ticket sales for conferences and events.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/pretix/pretix-ubuntu.sh
chmod +x pretix-ubuntu.sh
sudo bash pretix-ubuntu.sh
```
