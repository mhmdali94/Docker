## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/downloads/nzbget/nzbget-ubuntu.sh
chmod +x nzbget-ubuntu.sh
sudo bash nzbget-ubuntu.sh
```
