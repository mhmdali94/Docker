Automated installer for [Glance](https://github.com/glanceapp/glance) — a self-hosted dashboard that puts all your feeds and services in one place.

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/management/glance/glance-ubuntu.sh
chmod +x glance-ubuntu.sh
sudo bash glance-ubuntu.sh
```
