# AzuraCast — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [AzuraCast](https://www.azuracast.com) — a self-hosted, all-in-one web radio management suite.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/azuracast/azuracast-ubuntu.sh
chmod +x azuracast-ubuntu.sh
sudo bash azuracast-ubuntu.sh
```
