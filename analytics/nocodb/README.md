# NocoDB — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [NocoDB](https://nocodb.com/) — open-source Airtable alternative. Turn any SQL database into a smart spreadsheet with a no-code interface, REST/GraphQL APIs, and integrations.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/analytics/nocodb/nocodb-ubuntu.sh
chmod +x nocodb-ubuntu.sh
sudo bash nocodb-ubuntu.sh
```

## 🔑 Credentials

No default credentials — create your admin account on first visit.

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8088` | NocoDB Web UI |

## 💻 Connect

```bash
# Web UI
http://SERVER_IP:8088
```
