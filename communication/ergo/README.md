# Ergo IRC Server — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Ergo IRC Server](https://ergo.chat) — a modern IRC server (ircd) with built-in services and bouncer.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/communication/ergo/ergo-ubuntu.sh
chmod +x ergo-ubuntu.sh
sudo bash ergo-ubuntu.sh
```
