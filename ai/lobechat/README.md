# LobeChat — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [LobeChat](https://lobehub.com) — a modern, beautiful AI chat UI supporting OpenAI, Claude, Gemini, Ollama and more.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/ai/lobechat/lobechat-ubuntu.sh
chmod +x lobechat-ubuntu.sh
sudo bash lobechat-ubuntu.sh
```
