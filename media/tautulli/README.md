## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/tautulli/tautulli-ubuntu.sh
chmod +x tautulli-ubuntu.sh
sudo bash tautulli-ubuntu.sh
```
