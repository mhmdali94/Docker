# Monica

Open-source personal CRM — track relationships, interactions, reminders, and notes about people you care about.

## Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/monica/monica-ubuntu.sh
chmod +x monica-ubuntu.sh
sudo bash monica-ubuntu.sh
```

## What It Installs

- **Monica** — personal CRM application
- **MariaDB** — primary database

## Credentials

| Field | Value |
| --- | --- |
| URL | http://\<server-ip\>:8096 |
| Setup | Register on first visit |

## Ports

| Port | Service |
| --- | --- |
| 8096 | Monica Web UI |

## Connect

Register your account at `http://<server-ip>:8096`. Monica is single-user by default — one account per instance for personal use.
