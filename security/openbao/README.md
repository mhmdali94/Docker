# OpenBao — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [OpenBao](https://openbao.org) — the Linux Foundation fork of HashiCorp Vault — secrets management (dev mode demo).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/security/openbao/openbao-ubuntu.sh
chmod +x openbao-ubuntu.sh
sudo bash openbao-ubuntu.sh
```
