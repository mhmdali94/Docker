## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/beaverhabits/beaverhabits-ubuntu.sh
chmod +x beaverhabits-ubuntu.sh
sudo bash beaverhabits-ubuntu.sh
```
