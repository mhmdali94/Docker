# Roundcube — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Roundcube](https://roundcube.net) — a browser-based multilingual IMAP webmail client.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/email/roundcube/roundcube-ubuntu.sh
chmod +x roundcube-ubuntu.sh
sudo bash roundcube-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Login | Any mailbox credentials from your IMAP server |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8151` | Web UI |

## 💻 Connect

```bash
http://SERVER_IP:8151
```
