# ArangoDB — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [ArangoDB](https://arangodb.com) — a multi-model database: documents, graphs and key/value in one engine.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/databases/arangodb/arangodb-ubuntu.sh
chmod +x arangodb-ubuntu.sh
sudo bash arangodb-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Username | `root` |
| Password | Auto-generated (shown at install) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8529` | Web UI + API |

## 💻 Connect

```bash
http://SERVER_IP:8529
```
