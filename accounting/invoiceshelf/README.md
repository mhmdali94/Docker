# InvoiceShelf — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [InvoiceShelf](https://invoiceshelf.com) — beautiful invoicing for freelancers and small businesses (maintained Crater fork).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/accounting/invoiceshelf/invoiceshelf-ubuntu.sh
chmod +x invoiceshelf-ubuntu.sh
sudo bash invoiceshelf-ubuntu.sh
```
