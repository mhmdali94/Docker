## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/management/komodo/komodo-ubuntu.sh
chmod +x komodo-ubuntu.sh
sudo bash komodo-ubuntu.sh
```
