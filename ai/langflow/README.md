## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/ai/langflow/langflow-ubuntu.sh
chmod +x langflow-ubuntu.sh
sudo bash langflow-ubuntu.sh
```
