# Twenty

Open-source CRM — companies, contacts, deals, and custom data objects (Salesforce alternative).

## Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/twenty/twenty-ubuntu.sh
chmod +x twenty-ubuntu.sh
sudo bash twenty-ubuntu.sh
```

## What It Installs

- **Twenty** — modern open-source CRM
- **PostgreSQL** — primary database
- **Redis** — cache and task queue

## Credentials

| Field | Value |
| --- | --- |
| URL | http://\<server-ip\>:3300 |
| Setup | Register on first visit |

## Ports

| Port | Service |
| --- | --- |
| 3300 | Twenty Web UI |

## Connect

Open `http://<server-ip>:3300` and create your workspace. The demo login form is pre-filled for convenience. Invite teammates via Settings → Members.
