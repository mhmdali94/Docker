# Part-DB — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Part-DB](https://docs.part-db.de) — inventory management for electronic components, with KiCad integration.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/erp/part-db/part-db-ubuntu.sh
chmod +x part-db-ubuntu.sh
sudo bash part-db-ubuntu.sh
```
