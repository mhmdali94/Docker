# PeaNUT — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [PeaNUT](https://github.com/Brandawg93/PeaNUT) — a tiny dashboard for your UPS via Network UPS Tools (NUT).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/monitoring/peanut/peanut-ubuntu.sh
chmod +x peanut-ubuntu.sh
sudo bash peanut-ubuntu.sh
```
