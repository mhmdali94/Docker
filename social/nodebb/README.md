# NodeBB — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [NodeBB](https://nodebb.org) — a modern real-time forum platform built on Node.js.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/social/nodebb/nodebb-ubuntu.sh
chmod +x nodebb-ubuntu.sh
sudo bash nodebb-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Mongo host | `nodebb-mongo` |
| Mongo user | `nodebb` |
| Mongo password | Auto-generated (shown at install) |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `4567` | Web UI |

## 💻 Connect

```bash
http://SERVER_IP:4567
```
