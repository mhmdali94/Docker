## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/gaming/vintage-story/vintage-story-ubuntu.sh
chmod +x vintage-story-ubuntu.sh
sudo bash vintage-story-ubuntu.sh
```
