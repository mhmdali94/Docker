# Joomla — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Joomla](https://www.joomla.org) — the flexible open-source CMS powering millions of sites.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/cms/joomla/joomla-ubuntu.sh
chmod +x joomla-ubuntu.sh
sudo bash joomla-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|

| Password | Auto-generated (shown at install) |
