# HyperDX — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [HyperDX](https://www.hyperdx.io) — open-source observability — logs, traces, errors and session replay in one UI.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/monitoring/hyperdx/hyperdx-ubuntu.sh
chmod +x hyperdx-ubuntu.sh
sudo bash hyperdx-ubuntu.sh
```
