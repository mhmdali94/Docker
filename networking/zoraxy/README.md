# Zoraxy — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Zoraxy](https://zoraxy.aroz.org) — an all-in-one reverse proxy and forwarding tool with a friendly web UI.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/networking/zoraxy/zoraxy-ubuntu.sh
chmod +x zoraxy-ubuntu.sh
sudo bash zoraxy-ubuntu.sh
```
