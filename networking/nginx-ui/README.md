# Nginx UI — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Nginx UI](https://nginxui.com) — a modern web panel for managing nginx — sites, TLS, logs, config editor.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/networking/nginx-ui/nginx-ui-ubuntu.sh
chmod +x nginx-ui-ubuntu.sh
sudo bash nginx-ui-ubuntu.sh
```
