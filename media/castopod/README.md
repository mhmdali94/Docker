# Castopod — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Castopod](https://castopod.org) — host your podcasts with built-in analytics and fediverse support.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/castopod/castopod-ubuntu.sh
chmod +x castopod-ubuntu.sh
sudo bash castopod-ubuntu.sh
```
