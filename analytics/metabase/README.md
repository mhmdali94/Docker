# Metabase — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Metabase](https://www.metabase.com/) — open-source BI and dashboarding tool. Ask questions and build charts from your databases without writing SQL. Connects to PostgreSQL, MySQL, MongoDB, and more.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/analytics/metabase/metabase-ubuntu.sh
chmod +x metabase-ubuntu.sh
sudo bash metabase-ubuntu.sh
```

## 🔑 Credentials

No default credentials — create your admin account on first visit.

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `3007` | Metabase Web UI |

## 💻 Connect

