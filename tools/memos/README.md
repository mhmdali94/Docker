# Memos — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Memos](https://usememos.com/) — lightweight, privacy-first note-taking service. A self-hosted Flomo/Twitter-style quick capture tool for thoughts, links, and ideas.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/memos/memos-ubuntu.sh
chmod +x memos-ubuntu.sh
sudo bash memos-ubuntu.sh
```

## 🔑 Credentials

No default credentials — create your admin account on first visit.

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `5230` | Memos Web UI |

## 💻 Connect

```bash
# Web UI
```
