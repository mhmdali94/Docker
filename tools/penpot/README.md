> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Penpot](https://penpot.app) — the open-source design & prototyping platform (Figma alternative).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/penpot/penpot-ubuntu.sh
chmod +x penpot-ubuntu.sh
sudo bash penpot-ubuntu.sh
```
