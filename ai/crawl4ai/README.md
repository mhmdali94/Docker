# Crawl4AI — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Crawl4AI](https://crawl4ai.com) — an LLM-friendly web crawler and scraper that returns clean Markdown.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/ai/crawl4ai/crawl4ai-ubuntu.sh
chmod +x crawl4ai-ubuntu.sh
sudo bash crawl4ai-ubuntu.sh
```
