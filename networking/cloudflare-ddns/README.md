# Cloudflare DDNS — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Cloudflare DDNS](https://github.com/favonia/cloudflare-ddns) — tiny dynamic-DNS updater for Cloudflare — keeps your domain pointed at your changing home IP.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/networking/cloudflare-ddns/cloudflare-ddns-ubuntu.sh
chmod +x cloudflare-ddns-ubuntu.sh
sudo bash cloudflare-ddns-ubuntu.sh
```
