# GraphHopper — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [GraphHopper](https://www.graphhopper.com) — a fast self-hosted routing engine (driving/cycling/walking directions) on OSM data.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/maps/graphhopper/graphhopper-ubuntu.sh
chmod +x graphhopper-ubuntu.sh
sudo bash graphhopper-ubuntu.sh
```
