# draw.io — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [draw.io](https://www.drawio.com) — self-hosted diagramming (flowcharts, UML, network diagrams).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/drawio/drawio-ubuntu.sh
chmod +x drawio-ubuntu.sh
sudo bash drawio-ubuntu.sh
```
