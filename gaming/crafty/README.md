# Crafty Controller — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Crafty Controller](https://craftycontrol.com) — a web panel to create and manage multiple Minecraft servers.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/gaming/crafty/crafty-ubuntu.sh
chmod +x crafty-ubuntu.sh
sudo bash crafty-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Login | See `config/default-creds.txt` after first start |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8433` | Web UI (HTTPS) |
| `25565-25566` | Minecraft servers |

## 💻 Connect

```bash
https://SERVER_IP:8433
```
