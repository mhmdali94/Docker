# Omada Controller — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Omada Controller](https://www.tp-link.com/omada-sdn/) — the TP-Link Omada SDN controller for EAP access points, switches and routers.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/networking/omada/omada-ubuntu.sh
chmod +x omada-ubuntu.sh
sudo bash omada-ubuntu.sh
```
