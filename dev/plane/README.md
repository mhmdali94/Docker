# Plane — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Plane](https://plane.so/) — open-source project management tool. Track issues, plan sprints, manage cycles, and build roadmaps. A self-hosted alternative to Linear and Jira.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/dev/plane/plane-ubuntu.sh
chmod +x plane-ubuntu.sh
sudo bash plane-ubuntu.sh
```

## 🔑 Credentials

No default credentials — create your workspace and admin account on first visit.

| Port | Purpose |
