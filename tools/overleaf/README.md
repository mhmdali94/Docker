# Overleaf — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Overleaf](https://www.overleaf.com) — the collaborative LaTeX editor, self-hosted (Community Edition).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/overleaf/overleaf-ubuntu.sh
chmod +x overleaf-ubuntu.sh
sudo bash overleaf-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Admin | Created at `/launchpad` on first visit |
