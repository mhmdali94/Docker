# Kanboard — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Kanboard](https://kanboard.org) — minimalist kanban project management focused on simplicity.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/project-management/kanboard/kanboard-ubuntu.sh
chmod +x kanboard-ubuntu.sh
sudo bash kanboard-ubuntu.sh
```
