## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/databases/cloudbeaver/cloudbeaver-ubuntu.sh
chmod +x cloudbeaver-ubuntu.sh
sudo bash cloudbeaver-ubuntu.sh
```
