# SillyTavern — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [SillyTavern](https://sillytavern.app) — an advanced LLM frontend for roleplay and power users.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/ai/sillytavern/sillytavern-ubuntu.sh
chmod +x sillytavern-ubuntu.sh
sudo bash sillytavern-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|

| Password | Auto-generated (shown at install) |
