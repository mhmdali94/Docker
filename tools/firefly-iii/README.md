# Firefly III

Self-hosted personal finance manager with double-entry bookkeeping, budgets, and reports.

## Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/firefly-iii/firefly-iii-ubuntu.sh
chmod +x firefly-iii-ubuntu.sh
sudo bash firefly-iii-ubuntu.sh
```

## What It Installs

- **Firefly III** — personal finance application
- **MariaDB** — primary database

## Credentials

| Field | Value |
| --- | --- |
| URL | http://\<server-ip\>:8095 |
| Setup | Register on first visit |

## Ports

| Port | Service |
| --- | --- |
| 8095 | Firefly III Web UI |

## Connect

Register your account at `http://<server-ip>:8095`. Set up your accounts (checking, savings, credit cards), then start logging transactions or import from CSV.
