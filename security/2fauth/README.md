# 2FAuth — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [2FAuth](https://docs.2fauth.app) — a web app to manage and generate your two-factor (TOTP) codes.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/security/2fauth/2fauth-ubuntu.sh
chmod +x 2fauth-ubuntu.sh
sudo bash 2fauth-ubuntu.sh
```
