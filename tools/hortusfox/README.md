> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [HortusFox](https://www.hortusfox.com) — collaborative plant management — track your plants, tasks and inventory.

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/hortusfox/hortusfox-ubuntu.sh
chmod +x hortusfox-ubuntu.sh
sudo bash hortusfox-ubuntu.sh
```
