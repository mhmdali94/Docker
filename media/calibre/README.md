# Calibre — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Calibre](https://calibre-ebook.com) — the full Calibre e-book manager running in your browser (KasmVNC).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/calibre/calibre-ubuntu.sh
chmod +x calibre-ubuntu.sh
sudo bash calibre-ubuntu.sh
```
