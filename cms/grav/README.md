# Grav — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Grav](https://getgrav.org) — a fast, flat-file CMS — no database needed.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/cms/grav/grav-ubuntu.sh
chmod +x grav-ubuntu.sh
sudo bash grav-ubuntu.sh
```
