# Vikunja

Open-source task manager — lists, kanban, Gantt, and team collaboration (Todoist alternative).

## Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/vikunja/vikunja-ubuntu.sh
chmod +x vikunja-ubuntu.sh
sudo bash vikunja-ubuntu.sh
```

## What It Installs

- **Vikunja** — all-in-one task management server + frontend
- **MariaDB** — primary database

## Credentials

| Field | Value |
| --- | --- |
| URL | http://\<server-ip\>:3456 |
| Setup | Register on first visit |

## Ports

| Port | Service |
| --- | --- |
| 3456 | Vikunja Web UI |

## Connect

Register your first account at `http://<server-ip>:3456`. The first registered user automatically becomes the admin.
