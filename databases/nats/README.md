# NATS — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [NATS](https://nats.io) — a high-performance messaging system with JetStream persistence.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/databases/nats/nats-ubuntu.sh
chmod +x nats-ubuntu.sh
sudo bash nats-ubuntu.sh
```
