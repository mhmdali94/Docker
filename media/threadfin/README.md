# Threadfin — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [Threadfin](https://github.com/Threadfin/Threadfin) — an M3U proxy that presents IPTV playlists as a DVR tuner to Plex/Jellyfin/Emby.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/threadfin/threadfin-ubuntu.sh
chmod +x threadfin-ubuntu.sh
sudo bash threadfin-ubuntu.sh
```
