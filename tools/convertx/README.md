## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/tools/convertx/convertx-ubuntu.sh
chmod +x convertx-ubuntu.sh
sudo bash convertx-ubuntu.sh
```
