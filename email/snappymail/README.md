# SnappyMail — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [SnappyMail](https://snappymail.eu) — a fast, lightweight webmail client (RainLoop successor).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/email/snappymail/snappymail-ubuntu.sh
chmod +x snappymail-ubuntu.sh
sudo bash snappymail-ubuntu.sh
```

## 🔑 Credentials

| Field | Value |
|-------|-------|
| Admin user | `admin` — password in `data/_data_/_default_/admin_password.txt` |

## 🌐 Ports

| Port | Purpose |
|------|---------|
| `8226` | Web UI |

## 💻 Connect

```bash
http://SERVER_IP:8226
```
