# RSS-Bridge — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [RSS-Bridge](https://rss-bridge.org) — generates RSS feeds for websites that lack them (YouTube, X, Telegram, hundreds more).

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/media/rss-bridge/rss-bridge-ubuntu.sh
chmod +x rss-bridge-ubuntu.sh
sudo bash rss-bridge-ubuntu.sh
```
