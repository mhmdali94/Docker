# ZTNET — Docker Setup

> ⚠️ **FOR DEMO / TESTING PURPOSES ONLY — NOT INTENDED FOR PRODUCTION USE.**

Automated installer for [ZTNET](https://ztnet.network) — a self-hosted ZeroTier network controller with a modern web UI.

**Made by:** Mohammed Ali Elshikh — [prismatechwork.com](https://prismatechwork.com)

---

## 🛠 Usage

```bash
wget https://raw.githubusercontent.com/mhmdali94/Docker/main/vpn/ztnet/ztnet-ubuntu.sh
chmod +x ztnet-ubuntu.sh
sudo bash ztnet-ubuntu.sh
```
